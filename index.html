Политика конфиденциальности

Tournament Live
Последнее обновление: октябрь 2026 года

1. Введение

Tournament Live («Tournament Live», «мы», «нас» или «приложение») — мобильное приложение для проведения и прямой трансляции спортивных мероприятий, включая турниры по каратэ.

Настоящая Политика конфиденциальности объясняет, какие данные обрабатываются приложением, для каких целей они используются, куда передаются и как хранятся.

Мы стремимся обрабатывать только те данные, которые необходимы для работы функций приложения.

2. Какие данные обрабатывает приложение

Камера

Tournament Live использует камеру устройства для захвата видеопотока во время прямой трансляции.

Видео с камеры обрабатывается приложением на устройстве и передаётся в режиме реального времени на RTMP-адрес, указанный для конкретной трансляции.

Tournament Live не сохраняет видеозаписи камеры на собственных серверах.

Микрофон

Tournament Live использует микрофон устройства для захвата звука во время прямой трансляции.

Аудиоданные передаются в режиме реального времени вместе с видеопотоком на настроенный RTMP-адрес.

Tournament Live не сохраняет аудиозаписи с микрофона на собственных серверах.

Идентификатор установки

При первом запуске приложение создаёт случайный уникальный идентификатор установки (UUID v4).

Этот идентификатор:

  • создаётся приложением случайным образом;
  • хранится локально на устройстве;
  • не создаётся на основе IDFA;
  • не создаётся на основе аппаратного идентификатора устройства;
  • не используется для отслеживания пользователя между различными приложениями;
  • может передаваться на сервер Tournament Live вместе с запросами конфигурации, чтобы сервер мог различать отдельные установки приложения.

Идентификатор установки не используется для установления личности пользователя.

При удалении приложения локально сохранённый идентификатор установки удаляется вместе с данными приложения.

Информация об устройстве

Приложение может локально получать техническую информацию, необходимую для работы и настройки трансляции, включая:

  • модель устройства;
  • версию операционной системы;
  • версию приложения;
  • доступные технические возможности устройства.

Эта информация используется приложением локально для выбора подходящих параметров работы и качества трансляции.

Если такая информация не требуется серверу для конкретной функции, она не передаётся на сервер Tournament Live.

Информация о сетевом подключении

Приложение может определить тип сетевого подключения устройства, например Wi-Fi или мобильную сеть.

Эта информация используется локально для адаптации параметров трансляции и не используется для отслеживания местоположения пользователя.

3. Для чего используются данные

Обрабатываемые приложением данные используются для следующих целей:

  • захват и передача видео и аудио во время прямой трансляции;
  • получение конфигурации турнира после сканирования QR-кода или ввода PIN-кода;
  • идентификация конкретной установки приложения при запросах конфигурации;
  • настройка параметров трансляции с учётом возможностей устройства и сетевого подключения;
  • обеспечение стабильной работы функций приложения.

Мы не используем данные приложения для поведенческой рекламы или отслеживания пользователя между приложениями и веб-сайтами.

4. Передача данных

Передача видеопотока и аудиопотока

Во время прямой трансляции видео и аудио передаются в режиме реального времени на RTMP-сервер, указанный для трансляции.

В зависимости от настроек трансляции таким сервером может быть сторонняя платформа потокового вещания, например VK, YouTube или другой совместимый RTMP-сервис.

После передачи на соответствующий RTMP-сервер дальнейшая обработка, хранение и публикация потока регулируются политикой конфиденциальности и условиями соответствующего сервиса.

Tournament Live не использует видеопоток или аудиопоток для рекламы, аналитического профилирования или отслеживания пользователей.

Передача идентификатора установки

UUID установки может передаваться на сервер Tournament Live вместе с запросами конфигурации.

Этот идентификатор используется для технического распознавания конкретной установки приложения и не предназначен для установления личности пользователя.

Третьи лица

Мы не продаём и не предоставляем персональные данные пользователей третьим лицам в рекламных целях.

Приложение не содержит сторонних рекламных SDK или сторонних SDK аналитики.

Если пользователь самостоятельно указывает сторонний RTMP-сервис для трансляции, поток передаётся этому сервису исключительно для выполнения функции прямой трансляции.

5. Аналитика и отслеживание

Tournament Live не использует:

  • рекламный идентификатор IDFA для отслеживания;
  • сторонние рекламные SDK;
  • сторонние аналитические SDK;
  • технологии межсайтового или межприложенческого отслеживания;
  • контакты пользователя;
  • данные о местоположении пользователя.

Приложение также не создаёт пользовательский профиль для рекламных или маркетинговых целей.

6. Хранение данных

Видео и аудио с камеры и микрофона не сохраняются на серверах Tournament Live.

Они передаются в режиме реального времени на RTMP-сервер, указанный для трансляции.

Локальные настройки приложения и идентификатор установки хранятся на устройстве.

Срок хранения идентификатора установки связан с периодом существования локальных данных приложения. При удалении приложения локальные данные, включая идентификатор установки, удаляются из хранилища приложения.

Если сторонняя платформа, используемая пользователем для трансляции, сохраняет видеозапись или другие данные трансляции, срок и условия такого хранения определяются соответствующей платформой.

7. QR-коды и PIN-коды турниров

Tournament Live может использовать QR-код или PIN-код для получения конфигурации конкретного турнира.

QR-код или PIN-код используются для идентификации и загрузки соответствующей конфигурации турнира.

Приложение не использует QR-код или PIN-код для рекламного отслеживания пользователя.

8. Разрешения устройства

Для работы основных функций приложения могут запрашиваться следующие разрешения:

Камера — для захвата видео во время прямой трансляции.

Микрофон — для захвата аудио во время прямой трансляции.

Без соответствующего разрешения камеры или микрофона соответствующая функция приложения может быть недоступна.

9. Права пользователя

Пользователь может:

  • отказаться от предоставления разрешения на использование камеры или микрофона;
  • изменить предоставленные разрешения в настройках устройства;
  • удалить приложение вместе с его локальными данными;
  • обратиться к нам с вопросами относительно обработки данных.

Поскольку идентификатор установки не связан с учётной записью пользователя и не предназначен для идентификации личности, мы не используем его для установления личности пользователя.

10. Конфиденциальность детей

Tournament Live не предназначено специально для детей младше 13 лет.

Мы не стремимся сознательно собирать персональные данные детей младше 13 лет.

Если вы считаете, что ребёнок предоставил нам персональные данные, пожалуйста, свяжитесь с нами по указанным ниже контактным данным.

11. Безопасность

Мы применяем разумные технические и организационные меры для защиты данных, обрабатываемых приложением.

При этом ни один способ передачи или хранения данных через Интернет не может гарантировать абсолютную безопасность.

12. Изменения настоящей Политики конфиденциальности

Мы можем периодически обновлять настоящую Политику конфиденциальности.

При внесении изменений мы обновляем дату последнего изменения, указанную в верхней части этой страницы.

Privacy Policy

Tournament Live
Last updated: October 2026

1. Introduction

Tournament Live ("Tournament Live", "we", "us", or "the app") is a mobile application for conducting and live-streaming sporting events, including karate tournaments.

This Privacy Policy explains what data is processed by the application, why it is used, where it is transmitted, and how it is stored.

We aim to process only the data necessary to provide the application's functionality.

2. Data Processed by the Application

Camera

Tournament Live uses the device camera to capture video during a live stream.

Camera video is processed by the application on the device and transmitted in real time to the RTMP address configured for the particular stream.

Tournament Live does not store camera recordings on its own servers.

Microphone

Tournament Live uses the device microphone to capture audio during a live stream.

Audio data is transmitted in real time together with the video stream to the configured RTMP address.

Tournament Live does not store microphone recordings on its own servers.

Installation Identifier

When the application is launched for the first time, it generates a random unique installation identifier (UUID v4).

This identifier:

  • is randomly generated by the application;
  • is stored locally on the device;
  • is not generated from IDFA;
  • is not generated from a hardware device identifier;
  • is not used to track the user across different applications;
  • may be transmitted to the Tournament Live server together with configuration requests so that the server can distinguish individual application installations.

The installation identifier is not used to establish the identity of the user.

When the application is deleted, the locally stored installation identifier is deleted together with the application's local data.

Device Information

The application may locally access technical information required for operation and stream configuration, including:

  • device model;
  • operating system version;
  • application version;
  • available device capabilities.

This information is used locally by the application to select appropriate operating and streaming parameters.

If this information is not required by the server for a particular function, it is not transmitted to the Tournament Live server.

Network Connection Information

The application may determine the type of network connection, such as Wi-Fi or mobile network.

This information is used locally to adapt streaming parameters and is not used to track the user's location.

3. How Data Is Used

The data processed by the application is used for:

  • capturing and transmitting video and audio during live streams;
  • retrieving tournament configuration after scanning a QR code or entering a PIN;
  • identifying a specific application installation when requesting configuration;
  • adjusting streaming parameters based on device capabilities and network conditions;
  • providing and maintaining the application's functionality.

We do not use application data for behavioral advertising or for tracking users across applications or websites.

4. Data Sharing and Transmission

Video and Audio Transmission

During a live stream, video and audio are transmitted in real time to the RTMP server configured for the stream.

Depending on the stream configuration, this server may be a third-party streaming platform such as VK, YouTube, or another compatible RTMP service.

Once transmitted to the applicable RTMP server, further processing, storage, and publication of the stream are governed by the privacy policy and terms of the applicable service.

Tournament Live does not use video or audio streams for advertising, analytical profiling, or user tracking.

Installation Identifier

The installation UUID may be transmitted to the Tournament Live server together with configuration requests.

This identifier is used for the technical recognition of a specific application installation and is not intended to establish the user's identity.

Third Parties

We do not sell or provide users' personal data to third parties for advertising purposes.

The application does not contain third-party advertising SDKs or third-party analytics SDKs.

If the user independently specifies a third-party RTMP service for streaming, the stream is transmitted to that service solely to provide the live-streaming functionality.

5. Analytics and Tracking

Tournament Live does not use:

  • the IDFA advertising identifier for tracking;
  • third-party advertising SDKs;
  • third-party analytics SDKs;
  • cross-site or cross-app tracking technologies;
  • user contacts;
  • user location data.

The application does not create user profiles for advertising or marketing purposes.

6. Data Storage

Video and audio captured by the camera and microphone are not stored on Tournament Live servers.

They are transmitted in real time to the RTMP server configured for the stream.

Local application settings and the installation identifier are stored on the user's device.

The installation identifier is retained for as long as the application's local data exists. When the application is deleted, local application data, including the installation identifier, is deleted from the application's storage.

If a third-party platform used by the user stores a recording or other streaming data, the retention period and storage practices are governed by that platform.

7. Tournament QR Codes and PINs

Tournament Live may use a QR code or PIN to retrieve configuration for a specific tournament.

The QR code or PIN is used to identify and load the corresponding tournament configuration.

The application does not use QR codes or PINs for advertising or user tracking.

8. Device Permissions

The application may request the following permissions to provide its core functionality:

Camera — to capture video during live streaming.

Microphone — to capture audio during live streaming.

Without the appropriate camera or microphone permission, the corresponding application functionality may not be available.

9. User Rights

Users may:

  • deny permission to use the camera or microphone;
  • change granted permissions in the device settings;
  • delete the application together with its local data;
  • contact us with questions regarding data processing.

Because the installation identifier is not linked to a user account and is not intended to identify an individual, we do not use it to establish the user's identity.

10. Children's Privacy

Tournament Live is not specifically directed at children under the age of 13.

We do not knowingly seek to collect personal information from children under 13.

If you believe that a child has provided us with personal information, please contact us using the contact details below.

11. Security

We use reasonable technical and organizational measures to protect data processed by the application.

However, no method of transmitting or storing information over the Internet can guarantee absolute security.

12. Changes to This Privacy Policy

We may periodically update this Privacy Policy.

When changes are made, we will update the last-updated date displayed at the top of this page.
